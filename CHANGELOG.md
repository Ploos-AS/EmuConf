# Changelog

All notable changes to EmuConf are documented here.

## 0.1.0 - 2026-10-04

First development release.

- Canonical EmuConf Intermediate Model (ECIM).
- Import/export for WinUAE, FS-UAE, Amiberry, Fellow, FellowNG, and Copperline.
- Format detection, inspection, conversion, validation, compatibility scoring, and semantic diff.
- Fidelity classes: exact, mapped, approximate, unsupported, and preserved.
- Embeddable Rust API intended for consumers including Amilea and AmiVM.
- Fixtures and round-trip tests for the initial Amiga emulator family.
